# ZCode 执行器

大肥鱼支持 Codex、Claude Code、ZCode 三个真实执行器，以及 demo 演示执行器。设置中可以选择 ZCode 为默认执行器，也可在新建任务时单独选择，或让管家明确委派给 ZCode。

ZCode 需单独安装并完成登录。自动检测支持本机已验证的桌面安装路径和部分 Windows 注册表安装信息；未识别时，在设置中的 ZCode 路径填写 `ZCode.exe` 或其 `resources/glm/zcode.cjs` 的绝对路径。大肥鱼不复制 ZCode 的登录凭据。

当前适配针对 ZCode 3.14.3 自带 CLI 0.16.9。采用 `--mode edit` 并禁用 Bash，允许文件编辑；需要命令执行或交互授权的工作不保证完成。目录限制不能替代操作系统沙箱。模型由 ZCode 自身设置决定，任务模型及全局执行器模型应留空；传入模型名会明确报错，不会静默忽略。

ZCode 的本次 CLI 接口在结束时返回完整 JSON，任务运行中显示启动状态及可用诊断，不伪造逐步进度。成功需要退出码 0、有效 JSON、非空文本、sessionId 和 idle 终态；显式错误或权限拒绝不标记成功。取消和超时会终止本任务的进程树。结果大小限制为 2 MB。

执行器 succeeded 仍代表执行器报告完成。除本次明确执行的文件验收外，不代表系统自动证明所有业务成果正确。
