# Windows 安装版

应用显示名称已统一为“大肥鱼管家”。为保持升级兼容，内部应用标识、`dayu-desktop-pet` 数据目录和 `Programs/Dayu` 程序目录保持不变；不会重写历史聊天内容。

安装包：`desktop/release/Dafeiyu-Setup-0.1.0-x64.exe`。为当前 Windows 用户安装，不需要管理员权限；安装后创建“大肥鱼管家”桌面和开始菜单快捷方式。

已另外部署同一构建的免安装版到 `%LOCALAPPDATA%/Programs/Dayu/`，桌面 `大肥鱼管家.lnk` 指向其中的主程序。此版本已在项目目录之外验证通过，并在 PATH 仅含 Windows 系统目录的条件下完成聊天、演示任务、界面同步和退出清理。随包 Harness SDK 的初始化检查同样通过，不依赖本机开发用 Node.js。

本机直接双击“大肥鱼管家”即可使用。免安装版没有系统卸载项；退出后可移除应用目录和快捷方式，个人数据单独保留。

## 使用

- 双击“大肥鱼管家”启动。双击桌宠打开聊天面板。
- 安装版自带 Electron、Node.js 24 和后端依赖，无需先装开发环境，不打开命令行窗口。
- 在设置中填写个人 DeepSeek API Key。未配置密钥时可选择演示模式体验任务流程。
- Codex / Claude Code 是可选的外部执行器，需要在本机另行安装并登录；桌宠安装包不包含这两个工具，也不包含任何个人凭据。
- 关闭聊天面板只是隐藏面板；从托盘菜单选择“退出”会取消本应用的运行中任务并关闭后端。退出时请等待清理完成。

## 数据与升级

安装版使用 Electron 的用户应用数据目录，Windows 默认在 `%APPDATA%/dayu-desktop-pet/`。其中 `data/` 保存消息、任务及设置，`projects/` 为默认任务目录，`pet.json` 保存桌宠偏好。升级覆盖程序文件时保留数据，卸载默认也保留数据。

开发版仍使用项目 `.data/`，安装版不会自动复制或覆盖开发版的数据。API 密钥目前仍保存在本地配置文件中，尚未接入系统凭据保险库。

后端由应用拥有，监听系统分配的本机端口；应用通过 IPC 获取地址，用本地令牌连接。重复打开应用只激活现有实例。正常退出先通知后端取消任务、关闭数据库；超时后清理其进程树。

## 构建与验证

在 `desktop` 目录执行 `npm run package:win`。打包脚本先构建代码，使用根目录锁文件安装生产依赖，然后携带当前 Node.js 运行文件生成 x64 NSIS 安装包。当前 Node 许可文件对应 Node 24.20.0；升级运行环境时同步更新 `assets/Node-LICENSE`。

安装包未作商业代码签名。发布给其他用户前应配置签名证书。

发布检查包括：后端 58 项测试、前端 4 项连接测试、独立安装路径运行验证、演示聊天和任务的实时界面更新、退出后锁释放，以及安装包内 Harness SDK 的真实初始化握手（不发送模型请求）。

可通过 `大肥鱼管家.exe --dayu-verify=<检查输出目录>` 运行隔离验收。此模式会创建新的临时数据子目录，保存 `result.json` 和窗口截图，然后退出，不改变日常数据。云端 DeepSeek 调用及真实执行器任务仍需要用户配置后验收。
