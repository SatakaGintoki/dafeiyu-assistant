# 分阶段完善路线

## 已有基础（至 v0.2.14）

项目管理、模板、文件变更清单、有限范围检查点、安全恢复到新目录、配置检查、偏好管理、专注模式、短对话与原任务续做。版本管理与独立目录升级；通过验证才切换入口。公开准备门槛见 PUBLIC-PREVIEW.md。

通用事务项目、待办/日程/笔记、按需计划草案确认、重复日程、时区、持久提醒、免打扰和稍后提醒已落地。直连支持流式回复，聊天和详情支持常见 Markdown，桌宠已有眨眼、点头和思考表情。

发行包已拆为默认直连的 Lite 与额外包含官方 Harness 的 Full，移除未使用的 Office 可选二进制与调试映射，两版经过 Windows 原生验收。

## 下一阶段：可靠性与权限

- 正式代码签名与安装信任：需要发布者签名证书或合适的分发渠道；不能用代码绕过 Windows 应用控制。
- 检查点保留策略和空间管理、按文件差异预览、经确认后原位撤销；目前提供恢复副本。
- 文件删除/覆盖等工具级审批，独立操作系统沙箱；当前“先出计划”模板是工作流程约束，不是强制工具审批。
- 更完整的项目编辑、项目历史、模型连通检查，以及可导出的诊断包。

## 后续阶段：长期协作

- Claude 已支持停止后的指定会话恢复；其他执行器的原生会话恢复、运行中指令仍待实现，不能假称已实时注入。
- 已公开发布用户明确保存的项目记忆与编辑入口、事务指代工具及首次引导；自动长期摘要与真实模型多场景验收仍待完善。删除记忆或偏好不清除原始聊天。
- 可核实的用量计量、价格版本和费用预算；不同 CLI 提供不同数据，不能把估算当作账单。
- 日程提醒已有重启补查和免打扰；后续评估日历导入/同步及单独授权的定时执行工作流。
- 语音、更多个人办公能力及角色交互，在稳定性功能之后评估。
