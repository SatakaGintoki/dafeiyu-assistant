# 公开预览门槛

当前定位：Windows 桌面 AI 任务搭档，早期预览。没有真实用户试用反馈，自动验收不能替代市场需求验证。

## 本轮补齐

- 首次体验说明：无需模型凭据即可跑演示任务，清楚区分模型与执行器配置。
- 首次运行集成测试：缺少凭据明确报错，配置演示，完成任务，重启后保留配置、令牌和任务。
- Windows CI：锁文件安装、后端/前端检查、OpenAPI 一致性和真实 Electron 演示验收。不使用个人凭据。
- 跟踪文件与版本检查、敏感文件忽略规则、问题模板、贡献和隐私说明。

## 尚未达到正式公开发行要求

1. 作者选择代码许可证；复核第三方素材分发权限。未确认前不宣称“MIT 开源项目”。
2. 完整拟发布 Git 历史的秘密扫描和人工隐私审查。当前跟踪文件检查只是初筛；不要自动删除或改写历史。
3. Windows 安装包构建稳定性、包体、签名和升级回退。最近部署采用已验证的安装目录，不代表新的 NSIS 安装器已经成功产出。
4. 凭据迁移到系统凭据存储；工具审批与权限诊断仍待完善。不能把完全访问等同于每个动作均获准。
5. 在全新 Windows 机器上验证安装与卸载。隔离数据目录与 CI 都不等于真实干净机器测试。

## 下一轮优先级

先解决首次配置、安装与权限恢复，再做流式回复和成本显示。日程、语音及更多角色暂缓。收集反馈时衡量独立完成首次任务、遇错恢复和持续使用情况，不把测试通过数当作用户满意度。
